# Tarot Ri.der

## Description

This project was built using a MERN-stack single-page application implementing everything that I have learnt on this Bootcamp:
- a scalable MongoDB back end and Mongoose ODM
- a GraphQL API
- an Express.js and Node.js server
- React front end
- JWT for user authentication

The application was built to have a polished UI as well as be responsive and interactive. It was built with additional technologies like [Tarot API](https://tarotapi.dev/) and Ant design.  

Tarot reading is a way to explore have an internal dialogue about yourself by interpreting the meaning of each card relative to your queries.
